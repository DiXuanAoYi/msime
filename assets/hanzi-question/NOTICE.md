Offline character structure catalog

Source: Andrew West's BabelStone IDS Database, Unicode 16.0, file date 2025-06-27.
https://www.babelstone.co.uk/CJK/IDS.HTML

The author's permission and copyright waiver are retained in IDS.txt, lines 36-43.
source.json pins the original UTF-8 source SHA256. catalog.json is built offline by
scripts/build_hanzi_questions.py using pypinyin 0.55.0 (MIT, existing bundled attribution).
It omits unsupported/nonliteral structures rather than inventing missing components.

IDS describes glyph structure, not etymology. Regional glyphs can differ. Readings are
dictionary readings and may be polyphonic; an unavailable reading remains empty.
Aliases for everyday radical names are a search aid. Structural ambiguity returns
multiple candidates and can be narrowed with 上下/左右. Text-model answers are marked
separately. No model weights, user input, application history or network request is
included in this catalog.
