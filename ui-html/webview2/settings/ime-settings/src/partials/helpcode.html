句中辅助码
句中辅助码触发键
至少保留一个。分号在微软、搜狗、紫光双拼里也是 ing 韵母，只有在完整音节后才当触发键；按下后预编辑里同样显示为 `。大写字母：完整音节后直接敲大写的第一码，相当于反引号加这个字母（如 ulpbXihfa），第二码仍要大写；开启后这个位置的大写字母不再当末尾双码辅助
直接辅助码（万象式）
三码按完整双拼音节 + 一位辅码筛选，四码按完整音节 + 两位辅码筛选；歧义时保留普通切分和词图候选。四码单独输入按候选列表选择；嵌入句中需要下面启用的结束标记。与句中辅助码互斥：开启其中一个会关闭另一个，末尾辅助码由它统一识别。
直接辅助码句中四码标记
至少保留一个。四码在句中要标记出来，否则会让位给普通切分。斜杠：两位辅码后补一个 /；不勾时 / 照常当标点。第二位辅码大写：第二位辅码用大写敲；开启后大写字母只当四码的第二位辅码

自定义辅助码
把 UTF-8 编码的 .txt 辅助码文件放进下面的文件夹，点击“刷新方案”后即可在上方方案中选择。 每行写作 字=辅助码；设置中默认按文件名显示，可在文件开头用 # name: 中文名 和 # name_en: English name 注释指定方案名称。修改正在使用的方案文件后，需要切换一次方案或重启输入法才会生效。
