项目来源与使用方式

知语基于水杉输入法 Windows 版继续开发，借鉴青简输入法的候选释义、词库和输入体验。感谢上游作者、开源模型与词库维护者；各组件继续遵循其原有许可。

本地识别、发音和 OCR 模型按需下载，程序不会自动下载其他模型；未公开权重的项目不能直接下载使用。云服务由用户选择并配置 API，提供商、音色和语言能力以设置中的实际支持情况为准。

聊天按个人或群聊保存上下文，回复由你审阅后复制或上屏，不会自动发送。剪贴板和学习资料保存在本机；使用云服务时，相关请求内容会发送到所选提供商。

Server 端日志
排查 Server 通信和输入延迟时开启。记录慢请求阶段、候选窗、悬浮工具栏、菜单、焦点会话和通信状态，不记录按键、输入内容或候选文本。日志默认保存到桌面的“知语IME诊断日志.log”，复现后可直接发送该文件。
TSF 端日志
排查应用内预编辑和输入延迟时开启。TSF 日志会在内存中限量缓冲，并通过独立管道批量汇总到桌面的“知语IME诊断日志.log”；不记录按键、输入内容或候选文本。
