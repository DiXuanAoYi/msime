知语输入法 · Windows 10 / 11

从输入到表达，一处完成

本页对应当前本地版本。输入、资料管理可以离线使用；语音、OCR 和 AI 的可用能力取决于你选择的模型或服务。已有配置、聊天上下文及已下载模型继续保留。

开始输入与升级后使用

按 Win + Space 在系统输入法中选择“知语输入法”。支持全拼、双拼、五笔和辅助码；使用已经设置好的中英文切换键切到“英”后，也可以显示英文单词、句子和中文释义。中文候选上方的带调拼音可在“输入”中开关。

首次安装或更新 TSF 组件后，请保存工作，将原先打开的软件完整退出后重开；聊天软件可能需要从托盘退出。日常切换中英文、词库开关和设置调整无需反复重启。旧版本仍可能显示“水杉”，重开软件后加载新名称；不必卸载或清空用户数据。

剪贴板、常用语与语录

悬浮工具栏可打开剪贴板。左栏当前分类会高亮，所有资料均以滚动列表显示，不再翻页。剪贴内容相同文字合并，末尾 +N 是复制次数，次数多的排在前面。右键可复制、加入常用语、编辑或删除；双击剪贴内容、常用语、语录或软件词条可编辑。

在“管理分组 · 添加、重命名和转移”中点“新建”添加常用语或自定义语录，也可添加独立分组。语录包含经典语录、名人语录与青简诗词名句，可编辑后另存为自己的语录。语音收藏通过右键播放或复制音频；软件词库、学习记录与生词复习分别管理应用用词和学习进度。

问字、整句与候选发音

启用问字后，在拼音组词状态按 Ctrl + Alt + Q。例如 sangeshui 查询“淼”，caozitoujiarijiashi 查询“草”（草字头 + 日 + 十）。本地整句模型及整句补全在 AI 辅助中设置；启用补全后可按 Ctrl + Alt + Enter 触发。

按住 Ctrl 点击候选中文或旁边英文可发音，不会选词上屏。发音提供商、音色与模型参数在“语音与发音”中设置。上屏后立即按 Ctrl + Alt + Backspace，可在当前输入框、光标和文字仍匹配时撤销最近一次上屏。

本地语音、发音与方言

在“语音与发音”中选本地模型，查看下载大小后按需下载，再点“启动并使用”；正在使用的模型可直接停止或切换。不会自动下载其他模型。支持的本地 TTS 优先使用可用 GPU，无法使用时回退 CPU；首次加载与预热通常比后续播放耗时。

按 Ctrl + F9 开始或结束语音输入。语音工作台支持试听、音色选择、保存音频、收藏及导入识别；方言与民族语言按模型真实能力标注。完全离线时请选择本地识别和本地发音，并关闭云端润色。云端服务需要你自行填写 API 凭据；没有发布权重或不满足运行条件的模型会显示相应说明。

嘴替回复、润色与 AI 联想

先选联系人或群聊，检查按发言人保存的上下文，再填写意图、选择风格，生成多条可编辑回复。支持手动粘贴/导入，也支持已适配客户端的窗口读取；读取效果受客户端版本及当前窗口影响。程序不会自动发送回复，使用前由你选择、修改并复制或上屏。

文本润色及 AI 辅助的提示词模板支持自定义添加、删除、导入、导出，修改自动保存。聊天上下文按会话管理；使用云端模型时，所选上下文和请求内容会发往你配置的服务。

截图、OCR 与翻译

截图工作台合并长截图和 OCR，支持横向、纵向或双向拼接，也可导入照片。选择本地模型或自配云 OCR，提取文字、表格、公式及代码；结果和翻译都能编辑、复制、导出。公式、表格与代码请结合原图核对，模型未识别正确时可更换服务或手动修正。

翻译工作台提供对话、照片、字幕和屏幕翻译。对话支持并排/面对面、翻转及双方位置对调；字幕支持识别、翻译、编辑与导出。字幕编辑保护用于避免新结果覆盖正在修改的文字。屏幕翻译可提取画面文字并在原位覆盖显示。

词库、备份与问题排查

词库页集中管理学习词典、行业词典、青简领域输入词库和中译英词典，支持独立开关及导出。按软件独立词库在“剪贴板与资料库 → 软件词库”中管理。完整退出重开软件仍不能加载新版时，可保存工作后注销 Windows 再登录。

网络服务连接失败时先检查提供商地址、凭据、模型列表和下方代理设置；本地模型问题先检查下载状态及启动提示。关于页可按需启用诊断日志。升级会保留已有用户数据；卸载、手动清理或换电脑前，请额外备份用户数据目录与模型。

默认输入法 · 中文（简体）

点击后只把知语移到中文键盘列表首位，保留其他语言顺序与界面语言。启动或升级不会自动修改。
