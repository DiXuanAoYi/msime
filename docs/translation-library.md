# 可开关的离线词典与候选发音

设置 → 词库 → 离线翻译与学习词典。共 36 本：11 本学习词表、19 本行业词表、青简 5 个语言方向及水杉基础中英释义。

- 每本独立开关，保存后影响下一次候选翻译查询；重叠词可能仍由其他启用词典提供。个人自定义释义仍有优先权。
- 按名称搜索，按通用 / 学习 / 行业筛选。源词条数与含反向索引的检索条目数分别显示，避免重复计数。
- 每本可导出为 UTF-8 TSV，包含 `language / source / translation` 三列；开头四行保留来源、固定版本和许可说明。语言代码表示译文语言。保存对话框支持自行选择位置；关闭开关不会删除词典，也不影响导出。
- Ctrl 点击候选正文朗读原词；Ctrl 点击译文朗读前两条释义。只发音，不选择、提交候选或发送消息；Ctrl+Enter 继续用于选择更多释义。
- 发音使用本机 Windows SAPI 语音，离线运行；没有相应语言语音时提示音告知，需安装对应 Windows 语音后再试。语音输入仍维持本地识别、关闭云端润色。
