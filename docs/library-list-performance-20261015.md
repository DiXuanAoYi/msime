# 剪贴板与资料库：大列表切换性能修复（2026-10-15）

本轮仅改设置前端。保留原来的连续滚动、全量搜索、右键操作和双击编辑，不新增配置，不改聊天与模型存储，不推送或发布 GitHub。

## 原因与实现

语录包含 13,446 条青简诗词；原实现每次切换、搜索或刷新都为全部结果创建按钮、标题、正文和元信息节点。同一台电脑的隔离 Edge 测试中，14,506 条混合语录首次创建阻塞 2,715.9 毫秒，后续切换阻塞 1,242.4～1,472.0 毫秒。

- 结果大于 80 条时使用虚拟滚动，界面渲染当前可见部分及前后各 6 条的缓冲；520 像素视口通常 17 条。虚拟列表最多 48 条窗口记录，额外保留至多 1 条拥有键盘焦点的离屏记录。
- 数据和滚动总长度完整保留；小列表继续自然高度显示。没有分页或“加载更多”。
- 同一帧的滚动合并处理；切换类别、分组和搜索时取消旧任务，并以代次标记阻止旧回调覆盖新列表。
- 节点在相邻滚动窗口中复用，离开缓冲区及时释放。全量搜索不依赖当前已挂载的节点。
- Up/Down、Home/End 跨虚拟窗口操作；保留列表总条数、全局位置、选中高亮、右键菜单和编辑弹窗。

## 对照实测

使用同机、同一 Edge 隔离测试页及同样数据：13,446 条真实诗词，1,000 条自定义语录、60 条内置语录；另有 1,000 条常用语及各 2,000 条语音收藏、软件词条、学习记录。以下是同步事件处理耗时，不包含网络服务。

| 操作 | 修复前 | 修复后 |
|---|---:|---:|
| 首次进入 14,506 条语录 | 2715.9 ms | 26.1 ms |
| 后续进入语录 | 1242.4～1472.0 ms | 5.8～8.0 ms |
| 连续切换六个类别 | 4256.8 ms | 39.4 ms |
| 搜索目录最后一条诗句 | 97.5 ms | 18.0 ms |
| 语录活动记录节点 | 14,506 | 通常 17，末尾 10 |

完整报告保存在工作区 `work/library-performance-before.json` 和 `work/library-performance-final.json`；测试脚本为 `work/library-performance-benchmark.mjs`。这些数字来自本机受控测试，不表示所有电脑和数据量的耗时上限。
