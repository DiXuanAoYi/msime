# v0.10.3-chat.1 用户反馈复核

本次按用户在多次断网后的六项清单复核源码、打包输入和真实窗口。以下结果只覆盖列明的场景，不扩大为全部聊天软件、模型或云端质量验收。

| 要求 | 本版实现 | 核验 |
|---|---|---|
| 候选窗 Ctrl+Alt+Q 问字 | 使用 worker 返回的真实 generation；离线结果立即展示；等待、失败和结果显示在候选预编辑区，不提交提示文字 | 用户在真实 TSF 输入区确认 `sangeshui` → 淼 miǎo、`caozitoujiarijiashi` → 草 cǎo；错误与服务重启路径有原生回归 |
| 复杂部件问字 | 2–8 个部件、常见偏旁别名、上下/左右结构、递归拆解、多答案及说明；97,575 条汉字结构记录，保留来源和许可 | 草字头+日+十、木+口多解、左右人+木、四个月、缺少词表及无效结构等原生用例；不把不确定答案标为唯一正确 |
| 领域词库迁移 | 原控件整体移动到词库页；不另建一套数据或开关；11 本词库、按软件范围和导出保留 | 安装后的真实词库页展开卡片、来源、大小、开关、导出和软件范围均可见；持久化和导出内容由原生流程测试验证 |
| DeepSeek V4.1 Flash | 模型查询保留官方 name 和调用 id；显示名称和真实 API 名称同时可搜索；选择保存 id | 日常配置中的真实 GET /models 返回并显示 `DeepSeek-V4.1-Flash · deepseek-flash`；没有选模型或改写旧模型配置 |
| 翻译整合和注册网址 | 候选显示与整句工作台职责说明；离线词典集中在词库；单一有效在线服务，保留旧槽位；Tencent/Niutrans 等显示完整可点击网址 | 最终安装窗口切换两家后确认完整网址，并恢复原来的仅本地词典选择；配置再次比对通过。在线许可关闭时仍可查看提供商和注册网址，由生产界面测试覆盖，选择提供商不会自动启用许可 |
| 卡通互动 | 原生和 WebView2 候选窗增加悬停和点击动画；固定命中区域、不激活窗口；系统关闭动画时停用 | 用户实机确认动画正常、不会上屏且点击后能继续输入；通用 Image 变换恢复有原生 UI 用例 |
| 剪贴板重设计 | 左侧记录列表、右侧完整预览、搜索和分页、单一操作栏；保留常用语、分组、语音收藏、软件词库和复习 | 隔离样本的真实深色窗口检查；生产流程覆盖选择保持、手动复制、取消删除、收藏分组；删除/清空失败不假报成功，历史采用原子替换保存 |

## 构建、升级及交付

- 最终 Server CTest 4/4，含 731 原生用例和 105 共享消息夹具；x86/x64 TSF 各 16/16；原生 UI 53；设置前端 42 文件/226 测试，构建成功。
- clang-format 18.1.8 检查本次 C++，共享契约同步、版本资源和 GUI 库边界检查通过。最后一次 C++ 格式修正重新编译，并在完整隔离配置下重跑 Server 测试。
- 最终完整安装包安装成功、exit 0，无需重启 Windows。Server、Settings 和两架构注册的 TSF DLL 摘要与最终构建一致；95 个当前设置页资源及问字结构词表/原始来源与安装器载荷一致。
- 安装前为当前用户配置、聊天/资料库和数据库制作新的独立备份；安装后校验已有配置语义、凭据、聊天、词库和统计行。保留用户在测试期间主动修改的设置，不恢复为更早的配置。
- 原有 38 个模型/语音草稿按大小和 SHA256 比对；剪贴板正常新增仍遵循原有最近 50 条保留规则，早期测试备份保留旧历史。
- 不自动下载 ASR/TTS/OCR/QJM 模型，不自动向聊天软件发送消息。结构词表是随包离线字符资料，不是模型权重。
- Release 为个人仓库 `DiXuanAoYi/msime` 的 `v0.10.3-chat.1`。安装包为未签名版，Server `uiAccess=false`；不声称支持高完整性程序。提交、大小和 SHA256 以同版本 Release 的 manifest 与 SHA256SUMS 为准。

本次没有重新证明全部第三方编辑宿主、物理多屏 DPI、正式大模型/GPU 质量、全部云 TTS/OCR 或所有聊天客户端；旧版实测结果仍按原文范围保留。
