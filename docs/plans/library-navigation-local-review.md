# 剪贴板资料库导航与列表调整（本地验收）

用户要求先在本机修改、测试、安装；未经新的明确发布指令，不推送 GitHub 或上传 Release。本次仅调整设置前端，不改变原生协议、配置结构和资料存储。

## 最终行为

- 左栏当前分类以实心主题色、白色文字和加粗标示，深浅主题均适配。自定义分组也单独高亮，固定入口和分组入口不会同时选中。悬停保留选中色，键盘焦点有独立边框。
- 修正通用工作台按钮样式覆盖资料导航样式的问题，使选中配色在真实设置窗口生效；语录词典筛选保留独立的选中样式。
- 删除常用语、语录、语音收藏、软件词库、学习记录的右侧预览栏及其代码和样式，所有资料使用完整宽度的单列列表。文字、软件、编码、停用状态在列表中显示。
- 常用语、语录和软件词条仍可双击或右键编辑；语音收藏的播放移至右键菜单，复制音频和确认删除继续保留。切换和选中记录不会播放、复制、上屏或发送。
- 将现有“新建软件词条”按钮移到“保存软件开关”前面，仍使用同一入口与编辑弹窗，并保留当前软件作用范围；学习记录页不显示新建按钮。

## 验证

- 前端 42 个测试文件、245 项测试和 TypeScript/Vite 编译通过。覆盖各分类及自定义分组选中状态、刷新保留记录选择、弹窗编辑、语音收藏显式播放/复制和软件词条作用范围。
- Windows 隔离配置实机检查：深浅主题高亮可见；切换常用语、语录、自定义分组、语音收藏、软件词库和学习记录后布局及高亮正常；语录加载原有 13,446 条词典，右侧预览完全消失；语音收藏右键菜单包含播放/复制音频；软件词条停用标记可见，新建按钮紧靠保存软件开关之前。
- 实机使用合成资料，不操作真实聊天，不播放不存在的测试收藏，不触发删除确认。原生代码未改动，本次不重复运行此前的 TSF 和 Server 回归套件。

最终安装、配置/上下文/模型保留和载荷摘要以工作目录 `library-navigation-validation.json`、`library-navigation-install-final.log` 为准；最终升级前快照为 `library-navigation-final-user-backup-20261014`。关于页的延迟加载资源也校验版本标记，避免只替换首页而误显示旧版本。
