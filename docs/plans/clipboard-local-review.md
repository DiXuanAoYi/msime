# 剪贴板本地改版验收（0.10.4）

交付范围：只修改、构建和安装本机版本。未经用户再次明确要求，不推送 GitHub，不上传或发布 Release。保留现有配置、聊天上下文、用户词库和已下载模型，不下载新模型、不发送聊天消息。

## 界面和操作

- 原“实用功能”的剪贴板管理开关移至“剪贴板与资料库”，紧靠顶部“剪贴板”标题右侧，仅显示开关；保留无障碍名称。沿用 `utility.clipboard_history` 配置和快照回读，只有一个控件和一处事件装配。
- 左侧类型顺序为剪贴内容、常用语、语音收藏、生词复习、软件词库、学习记录。
- “清空”放在“刷新”左侧，移除原位置的清空按钮和“记录复制的文字”复选框。清空仅作用于剪贴记录，保留常用语、语音、词库和其他资料，执行前确认。
- 剪贴记录列表显示实际文字、保留换行，末尾为 `+N`。同文合并，复制次数按数字降序排列，相同次数保留最新顺序。
- 剪贴内容不显示右侧完整预览；复制、加入常用语、删除使用右键菜单。支持菜单键和 Shift+F10，选择记录不会自动复制或发送。
- 文字复制成功不显示“已复制，请自行粘贴；不会自动发送。”；复制失败仍保留错误反馈。

## 存储和兼容

旧的字符串数组读取为每条一次，支持原文和 Unicode。新格式为 `{"text":"…","copies":N}`，计数饱和上限为 2,147,483,647，仍只保留最新 50 项。读取排序不改变实际保留顺序。

写入使用原有跨进程互斥和原子替换。剪贴板序号在关闭系统剪贴板后获取，Server 与独立 Settings 按数据路径共享序号声明，避免同一次复制在双监听器中重复计数。序号只在保存成功后声明，旧或延迟通知不再重复计数。损坏文件不会在添加或删除时被覆盖。

当前页面每秒仅请求轻量剪贴记录，离开页面、窗口不可见或右键菜单打开时暂停；不会反复载入整份资料或弹出保存提示。
