聊天窗口读取与预回复 v0.9.9-chat.1（兼容性预发布）

使用
1. 登录客户端，打开要记录的会话。在设置 → 嘴替 · 回复 → 聊天窗口只读监测中扫描。
2. 选择识别出的标题，先检查“读取预览”的发言人和正文。填写账户标识、自己的会话昵称、独立会话编号，确认联系人/群类型后绑定。
3. 每个人/群使用独立编号，不同账户或软件使用不同编号。同名联系人/群不能靠标题可靠区分：切换账户或同名聊天前先停止并解除绑定，重新确认。标题变化需要重新绑定，不能自动合并。
4. 开始只读监测。每轮完成后按 3 秒计时器继续扫描，读取进程有 8.5 秒超时；首次或恢复读取只保存历史基线，不把旧消息当新消息。
5. 勾选“新消息自动准备回复”，后续明确的新消息将带上本会话近期上下文，使用下方模式和 3/5 条数量调用已配置的润色模型。默认关闭；离线记录不需要模型。
6. 新消息使旧草稿过期，自己发言或无法识别发言人的最新消息不触发回复。每条备选仅有手动复制按钮；不会点击聊天软件、填入输入框、模拟回车或发送。
7. 按会话保存的发言记录可读取、导出 JSON、删除。需要总结时，将导出的原话导入下方工作台的上下文，按“总结上下文”；工作台原文不会被摘要替代。
8. 停止监测、关闭或隐藏设置窗口会取消扫描与模型请求；重新打开不会自动启用。客户端重启后需重新扫描绑定。

实机适配与限制
- 微信 4.1.13：Qt 无障碍控件提取标题、成员数、已加载的文本；群昵称用 Windows 本机 OCR 补充。对最后一条消息，仅在当前会话摘要的完整正文、时间均匹配时，用摘要的显式姓名校正昵称；截断摘要、时间不符、旧消息均不推测。实机样本 4 条消息中 3 条识别出发言人，仍有 1 条未知。
- QQ NT 9.9.7.21804：改用当前窗口的本机 OCR 与气泡区域，绕过与可见内容不一致的 UIA 历史缓存。已实测当前群聊、当前文字及发言人；支持本次检测的深色布局。OCR 的标题装饰字符和昵称可能有误，须核对预览。未打开、未加载的消息仍读不到，特殊布局无法确认时暂停。
- 企业微信 5.0.11：窗口没有聊天无障碍控件，使用本机 OCR 和气泡区域识别。支持本次标准浅色布局，按画面边界定位聊天区并合并同一行标题片段。已实测群标题、群类型、本人气泡；现有群只有本人，真实其他成员发言尚缺样本，不能视为已完成多人群端到端验证。深色、特殊布局、超大窗口或最小化时暂停。服务/文件传输会话不触发预回复。
- 钉钉 8.2.0：Qt 消息列表提供“某人在某时发送了正文”，直接提取姓名、时间、正文；当前实机样本为本人会话，群类型不明时需手动确认，附件与无法识别的结构跳过。
- 飞书 7.72.8：普通群消息流使用稳定消息 ID、独立发言人和正文节点；话题视图分离主帖和楼中楼。公告、链接预览、点赞和输入框不作为正文。旧版社区话题布局未适配时明确暂停。
- 只读当前已加载内容，不点击、不翻页、不自动切换会话，不能采集后台所有未打开会话，也不能补齐客户端未加载的全部历史。图片、语音、附件不转写；客户端更新/主题变化可能影响结果。
- 无法证明消息连续、窗口不可读、会话标题切换或超时时暂停/重新建立基线；断层时要求重新核对，避免跨会话串写。未知时间明确留空，另保存本机观察时间；OCR 来源明确标记。

数据
独立文件 <DataDir>/chat-records.dat 使用 Windows 当前账户 DPAPI 加密、互斥访问、临时文件原子替换。100 个保存会话、20 个同时绑定、每会话 10000 条、总文件 32 MB 上限；超限报错并保留原文件。原话保留 90 天，下一次读取/操作时清理到期消息，不自动用摘要覆盖。停止读取不删除记录。
导出 JSON 是明文；Windows 账户/机器迁移前先导出。升级安装保留并迁移 chat-records.dat。不会读取客户端私有数据库、索取聊天账户密码、保存或上传截屏。OCR 图像仅短暂存在本机读取进程内存中。
启用预回复后，仅当前绑定会话的近期记录（约 46 KB）和触发消息（约 11.5 KB）发往“语音输入 → 润色”的模型地址；不会一次发送全部会话。自动草稿仅在页面内展示，不作为已发送事实写入记录。手动工作台的 reply-contexts.dat 与自动记录分开存储。

诊断
安装目录 server/MetasequoiaImeChatCapture.exe --diagnose 输出各软件可读状态、消息总数和已识别发言人数，不输出姓名和正文。读取组件默认标准输出含所读文本，仅开发排错使用，不要公开上传原始输出。
功能代码和测试不包含发送消息的 API。线上客户端测试只读取；已使用本机定时产生的合成群消息，完成原生设置页 → 自动检测新消息 → 已配置 DeepSeek → 3 条回复草稿的实测。没有上传真实聊天，也没有发送消息。
