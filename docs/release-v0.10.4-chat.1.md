# 知语输入法 v0.10.4-chat.1

本版汇总此前在本机验证的剪贴板与资料库改进、知语品牌与帮助更新，以及资料库大列表性能修复。基于水杉输入法继续开发，保留青简词库来源与许可说明。

## 主要变化

- 产品显示名统一为“知语输入法 / Zhiyu IME”，同步设置、安装器、开始菜单、TSF 注册描述、帮助及关于页。沿用原有 AppId、COM/profile GUID、数据目录、程序文件名与模型文件名。
- 剪贴内容显示原文，重复复制合并次数并按次数降序排列；复制、加入常用语、编辑与删除放到右键菜单。双击可编辑剪贴文本；合并重复项时保留次数，失败不覆盖原内容。
- 资料分类放在左侧并高亮当前位置；去掉右侧预览、分页和普通成功状态提示。保留可关闭的失败提示、失败草稿及后台刷新后的选中记录。
- 常用语与语录支持自定义分组和弹窗编辑；内置经典语录、名人语录及现有青简 13,446 条诗词名句。内置内容可编辑为本机自定义副本。
- 常用语、语录、语音收藏、软件词库、学习记录统一使用 70 CSS 像素的紧凑条目，不显示字符数。软件名、编码、停用状态、学习次数等业务信息保留。
- 大列表采用虚拟滚动与有限缓冲，取消过期渲染任务；保留全量搜索、滚动到底、Home/End/方向键、双击编辑与右键操作，避免切换时一次创建一万多条记录节点。
- 剪贴板管理开关放到“剪贴板”标题旁，清空按钮位于刷新之前；新建软件词条按钮位于保存软件开关之前。
- 升级沿用原配置、聊天上下文、剪贴记录、用户词库及已下载模型。可选模型由用户按需下载；回复仍需手动确认发送。

## 验证

- 最终前端 43 个测试文件、257 项测试、TypeScript/Vite 构建与契约同步检查通过。
- 最终 Server、Settings、x86/x64 TSF 构建通过；Server CTest 4/4，x86 与 x64 TSF 各 16/16 通过。
- 同机受控测试：14,506 条混合语录的同步切换阻塞由约 1.2～2.7 秒降至约 6～26 毫秒。实际速度受电脑与数据影响；本版每类 2,000 条资料测试仍只渲染可见窗口及少量缓冲，完整首尾导航与搜索正常。
- Windows 设置宿主已检查三个新增紧凑分类，以及深浅主题下的资料列表、语录大目录、右键菜单和编辑弹窗。已有本地升级曾校验 95 个界面资源、配置、聊天、剪贴次数及数据库记录，并逐字节核对 38 个模型/语音文件。

## 安装与升级

从本仓库 Release 下载 `MetasequoiaIME_Setup_v0.10.4-chat.1-unsigned.exe`，同页提供 `SHA256SUMS.txt`。此为未签名构建，不声称具有可信代码签名或可用的管理员窗口 uiAccess。源码对应本 Release 标签，可从 GitHub 下载源码归档；第三方许可随安装包保留。

运行安装器覆盖升级即可保留原配置与资料。保存工作后，把升级前已打开的软件完整退出再重开，以加载新版输入法组件及名称；部分聊天软件需从托盘退出。无需卸载输入法或清空原配置。

历史本地验收过程见 [资料库性能记录](library-list-performance-20261015.md)；其中“未推送”描述的是当时仅本地验收的阶段。本次在用户明确授权后同步源码并发布 Release，不上传用户配置、聊天记录、模型、测试缓存或本机备份。
