# 学习、截图与翻译工作台

新增 OCR 默认使用 Windows 本机识别，发音保留已有离线默认。升级沿用原有语音识别和润色开关，不改写用户已选择的服务。安装包不含新增模型权重，只有点击模型卡片的下载按钮才开始下载；卡片显示模型文件总大小。首次启动的 Python、CUDA 等运行依赖另计，可能需要数 GB 空间。关闭设置窗口不会暂停已经明确启动的模型下载。

## 提示词与资料库

“语音与发音”的润色提示词和“AI 辅助”的联想提示词都支持命名、添加、复制、删除、撤销删除以及 JSON 导入导出。编辑后自动保存。旧版三个自定义槽位中的非空内容会迁移为有名称的模板，原配置字段保留；导入按名称和内容去重合并。两类模板分别导出，避免把润色格式误用于候选 JSON。

“剪贴板与资料库”包含常用语、语录及自定义分组，最近复制内容、按软件词条、语音收藏和生词复习。悬浮工具栏的剪贴板图标可打开此页。资料可搜索并分页。按软件词条使用程序文件名（如 `Code.exe`）和输入编码匹配；支持软件独立开关、自动学习开关、使用频率开关和 JSON 导入导出。独立模式继续使用现有基础词典，但新造词、英文回车学习、调频和候选菜单修改只保存在对应软件。关闭后保留独立记录，恢复共享学习行为。删除分组会将其内容移动到保留分组。

语音工作台生成草稿后可点击“收藏语音”；收藏的是已经生成的 WAV，不会重新调用云服务。播放和复制均需手动操作，不会向聊天软件发送。生词复习使用已有学习记录，复习安排与原熟悉度统计分开保存。

中文候选上方显示词典生成的带调拼音，词组上下文用于多音字消歧。在外观设置中可以关闭“显示中文候选拼音（含声调）”，默认保持开启。人名、生僻词和专业术语仍可能存在词典未覆盖的读法。

刚上屏后，可按 **Ctrl+Alt+Backspace** 撤销本输入框内最后一次输入法提交。仅当原提交范围、文字、光标和焦点仍匹配时执行；切换输入框、移动光标或开始新一轮组合时不会盲目删除宿主内容。它不是任意应用历史操作的撤销器。

## 截图与 OCR

进入“截图 · OCR · 翻译”：

工作台分为“图片 · OCR”“文字 · 屏幕翻译”“对话翻译”“字幕”“模型与服务”。图片识别和文字翻译共用同一份可编辑原文，切换子页不会复制或清空内容。语音页也按发音、工作台、识别和润色分为子页；高级参数和凭据可按需展开。

1. 框选截图、导入本地图片，或手动打开摄像头拍照。
2. 长截图可以只启用左右、只启用上下，或同时启用，至少保留一个方向。框选后缓慢滚动，保持相邻画面大部分重叠，按 Esc 完成。最多捕获 60 帧；无法可靠对齐时明确报错，不拼凑不存在的内容。双方向需逐行经过目标区域。
3. 选择文字、表格、公式、代码或混合文档任务，点击识别。Windows OCR 默认离线；云 OCR 会发送当前图片到所选厂商。
4. 对照原图编辑结果，可复制或导出。表格以可编辑 HTML 保存，公式以 LaTeX 保存，原始识别 JSON 也可单独导出。复杂跨栏表格、手写公式、低清图片及代码缩进不能保证完全无误。

本地可选 PP-OCRv6、GLM-OCR、HunyuanOCR 和 PaddleOCR-VL。PP-OCRv6 适合轻量文字识别；结构化表格和公式请选择文档模型。模型文件从官方账号下载并逐个校验 SHA-256，视觉模型优先 CUDA，失败回退 CPU。Windows OCR 还取决于已安装的系统 OCR 语言包。

长图保持原像素分块识别，不再整体缩到 2048 像素；每块原始结果和坐标保留在 JSON 中。跨块表格、公式和多栏内容仍需核对。代码任务仅在逐行坐标及等宽字符尺度可靠时估算行首缩进，不猜测标点和下划线；估算与原始 OCR 一起保留。达到输出长度上限会明确提示结果不完整。

云端接入：[石榴智能](https://market.shiliuai.com/general-ocr)（APPCODE）、腾讯云（SecretId/SecretKey）、百度智能云（API Key/Secret Key）。设置页提供可点击的开通和文档链接。石榴当前接通的是通用文字接口，不把普通文字结果冒充结构化公式。腾讯旧公式接口已下线，因此此任务提示改用本地文档模型或百度；百度公式任务使用支持 `recg_formula` 的文档分析接口。相关云服务需要自行开通对应产品权限。

## 翻译与字幕

单独的翻译区可直接粘贴文字，也可翻译修改后的 OCR 原文。默认本机词典适合已收录词句；整段翻译可以选择已有文本润色 API、腾讯翻译、小牛翻译或自定义接口，点击翻译后才提交文字。

对话翻译支持双方语言选择、并排、面对面、对方内容 180° 翻转以及双方位置对调。译文仍可编辑。语言选择不代表所有云厂商都支持该语言，服务不支持时会显示错误。

屏幕翻译须手动框选并启动，定时识别框选区域、按识别坐标逐块覆盖变动文字，块外画面保持透明。文本模型可以批量翻译，译文通过编号严格对应原块。文档模型仅提供区域坐标时按区域覆盖；无坐标则明确降级，无法定位的部分可在编辑区查看。按 Esc 停止并清除；停止后可检查和编辑最近结果。译文超出原区域可能裁切，完整结果仍可保存。覆盖层不接管鼠标操作，捕获前会暂时隐藏以避免识别自身译文。

字幕支持麦克风或系统播放声音，沿用已经启动的本地 ASR 模型，约每 5 秒识别一段。开启“同时翻译”后使用上方选定翻译服务。点击完成可处理最后一段；立即停止会取消当前请求。支持 UTF-8、UTF-16、GB18030 的 SRT/VTT 导入，最多 1 MB / 2000 段；翻译保留时间轴，导出为 SRT。原文和译文可逐段编辑，手动修改不会被后续识别覆盖；高级 SRT 编辑仅追加新段，不重写已有内容。后续翻译失败仍保留已完成段，可切换上一个字幕草稿。开始新的音源采集会创建新稿，请先导出需要长期保留的内容。短分段边界可能影响断句和个别词的识别。

## 发音与方言

支持的本地 TTS 优先使用 GPU，GPU 不可用、内存不足或组件不兼容时回退 CPU，并显示实际运行设备。Kokoro 的某些 CUDA 组合会在原生组件内退出，独立进程会检测并回退，避免持续卡在启动状态。MOSS 允许部分 ONNX 算子回退 CPU。Voxtral 使用 Vulkan GPU 后端，并保留 CPU 回退。

Azure 音色列表提供上海话、粤语及晓晓方言模型支持的河南、陕西、四川、山西、安徽、湖南、甘肃、山东、辽宁和闽南语等选项。火山引擎预置 Vivi 已核实支持的东北、陕西、四川组合；其他音色通过“音色 ID | 方言代码”接入，须在控制台确认该音色和模型版本的方言能力。

MMS 中部藏语、安多藏语、哈萨克语、蒙古语（西里尔文字）和维吾尔语（阿拉伯文字）为原生文字转语音，需输入对应文字；不会自动将中文翻译。它们只有官方单音色，使用逐句生成与播放，不宣称句内流式。模型遵循 **CC-BY-NC-4.0，仅限非商业用途**。苏州话尚无已核实的内置音色，不能用上海话冒充。详细范围见 [方言支持说明](dialect-support.md)。

覆盖安装继续保留配置、聊天上下文、个人资料库、语音草稿、学习记录以及已下载模型。安装器会先停止输入法自身的本地模型服务及其工作进程，再替换运行组件；升级后可再次启动已下载模型。TSF DLL 的更新需要已打开的软件完整退出后重新打开才能加载；仅重新打开文档或关闭到托盘可能不够。
